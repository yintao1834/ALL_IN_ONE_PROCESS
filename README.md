# Smart Pipe Strain Data Processing Tool

This project is used to process strain data measured from a smart pipe system.

The main operation is performed by running:

```bash
python strain_gui.py
```

The GUI allows users to select specific filter ranges and visualize the strain data in real time. It is designed to make strain data checking, filtering, and preprocessing easier during smart pipe experiments.

## Main Features

* Load and process smart pipe strain data
* Select specific strain data ranges for filtering
* Apply filtering operations through a GUI
* Visualize strain data in real time

## Usage

Run the following command in the project directory:

```bash
python strain_gui.py
```

Then follow the GUI instructions to select the strain data range and check the visualization results.
